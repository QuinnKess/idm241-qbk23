Hover the pin, hover the Board button, then click Save.

TRIGGERS:

  • Pin (image)
    • Hover ON
    • Hover OFF
  • Board Button
    • Hover ON
    • Hover OFF
  • Save Button
    • Hover ON
    • Hover OFF
    • Click ON

RULES:

  • Pin (image):
    • Hover ON
      • Dark gray overlay fades in over the image
      • Board button with a down arrow appears top left
      • Red Save button appears top right
      • Share icon appears bottom right (white rounded square, black arrow)
    • Hover OFF
      • Overlay fades out
      • Board button, Save button and share icon disappear
  • Board Button:
    • Hover ON
      • Cursor changes to Finger
      • Gray rounded background appears behind "Board" and the down arrow
    • Hover OFF
      • Cursor changes back to default
      • Gray background disappears
  • Save Button:
    • Hover ON
      • Cursor changes to Finger
      • Button turns a slightly darker red
    • Hover OFF
      • Cursor changes back to default
      • Button goes back to normal red
    • Click ON
      • Pin is saved to the board shown on the Board button
      • Database updated with the pin added to that board
      • Button background changes from RED to BLACK
      • Button text "Save" changes to "Saved"
      • Down arrow on the Board button disappears
      • Board button text becomes an underlined link to the board
      • That board stays the default board for the next save

FEEDBACK:

  • Pin (image):
    • See: image darkens on hover and returns to normal on hover off
    • See: Board button, Save button and share icon appear and disappear with the overlay
  • Board Button:
    • See: pointer cursor and a gray rounded background on hover
    • See: after saving, the down arrow is gone and "Board" is underlined
  • Save Button:
    • See: pointer cursor and a darker red on hover
    • See: on click, the button turns black and reads "Saved"
  • Hear: none
  • Feel: none

LOOPS & MODES:

  • Loops:
    • Every pin in the feed has its own image overlay, Board button and Save button
    • Feed scrolls forever, so the microinteraction repeats on every new pin
    • Saved pin still shows "Saved" when hovered again
    • Last board used becomes the default board on the next pin
  • Modes:
    • Board picker: clicking the Board button opens a list of boards to save to instead (not built in this Alpha)
    • Logged out: clicking Save asks the user to log in or sign up
    • Touch (phone/tablet): no hover, so the overlay and buttons are always shown

URL

https://www.pinterest.com/

Object: Save Button

How to find it: log in to Pinterest, stay on the Home feed, and move the mouse over any pin. The red "Save" button appears in the top-right corner of the pin.

TRIGGERS:

  • Pin
    • Hover ON
    • Hover OFF
  • Save Button
    • Hover ON
    • Hover OFF
    • Click ON

RULES:

  • Pin:
    • Hover ON
      • Dark gray overlay appears over the pin image
      • Board name "Plugg" with a down arrow appears top left
      • Red "Save" button appears top right
      • Share icon appears bottom right
        • White rounded square, black arrow
    • Hover OFF
      • Overlay disappears
      • Board name, Save button and share icon disappear
  • Save Button:
    • Hover ON
      • Cursor changes to Finger
      • Button turns a slightly darker red
    • Hover OFF
      • Cursor changes back to default
      • Button goes back to normal red
    • Click ON
      • Pin is saved to the board shown on the left ("Plugg")
      • Database updated with the pin added to that board
      • Button background changes from RED to BLACK
      • Button text "Save" changes to "Saved"
      • Down arrow next to the board name disappears
      • Board name "Plugg" becomes an underlined link to the board
      • "Plugg" stays the default board for the next save

FEEDBACK:

  • Pin:
    • Hover ON
      • Dark gray overlay appears over the pin image
      • Board name "Plugg" with a down arrow appears top left
      • Red "Save" button appears top right
      • Share icon appears bottom right
        • White rounded square, black arrow
    • Hover OFF
      • Overlay disappears
      • Board name, Save button and share icon disappear
  • Save Button:
    • Hover ON
      • Cursor changes to Finger
      • Button turns a slightly darker red
    • Hover OFF
      • Cursor changes back to default
      • Button goes back to normal red
    • Click ON
      • Button background changes from RED to BLACK
      • Button text "Save" changes to "Saved"
      • Down arrow next to the board name disappears
      • Board name "Plugg" becomes an underlined link to the board

LOOPS/MODE:

  • Repeating Objects:
    • Every pin in the Home feed has its own Save button
    • Each one follows the same rules (hover shows the overlay, click changes "Save" to "Saved")
    • Scrolling down loads more pins, each with its own Save button
  • Additional Modules:
    • Board Button (top left)
      • Shows the board the pin will be saved to
      • Click opens the "Save" board picker
        • Search bar, "Top choices", "All boards" and "Create board"
        • Hover a board row: row turns light gray and a red "Save" button appears on it
        • Click the row's "Save" button: pin saves to that board
    • Share Icon (bottom right)
    • "Visit site" Button (bottom left)
  • Changes if Conditions Change:
    • Pin links to a website: "Visit site" button appears next to the share icon
    • Pin has no link: only the share icon shows
    • Pin is narrow (small window): board name is cut short (example: "A...")
    • After saving to a board: that board becomes the default board shown on other pins

VISUALS:

Black arrow = cursor position. Yellow rings = click.
